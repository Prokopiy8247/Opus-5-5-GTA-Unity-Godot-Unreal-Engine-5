# Port Halcyon — GTA-like sandbox on Unity

Оригинальная одиночная игра-песочница без миссий: островной город примерно 600×600 м, свободное исследование, транспорт, оружие, полиция, NPC, магазины, смена времени и погоды. Проект создан на Unity 6000.6.0f1 и URP; основные 3D-модели сделаны в Blender специально для игры.

> Это независимый учебный проект. Он не связан с Rockstar Games или серией Grand Theft Auto.

## Самый простой запуск — без Unity

Откройте страницу [Releases](https://github.com/Prokopiy8247/Opus-5-5-GTA-Unity-Godot-Unreal-Engine-5/releases/latest) и скачайте архив для своей системы.

### Windows 10/11 (64-bit)

1. Скачайте `Port-Halcyon-Windows-x64.zip`.
2. Полностью распакуйте архив в обычную папку. Не запускайте игру прямо из окна ZIP.
3. Запустите `PortHalcyon.exe`.
4. Если SmartScreen покажет предупреждение, нажмите «Подробнее» → «Выполнить в любом случае». Сборка не подписана коммерческим сертификатом.

Файл `.exe` должен оставаться рядом с папкой `PortHalcyon_Data` и остальными файлами из архива.

### macOS 12+ (Intel и Apple Silicon)

1. Скачайте `Port-Halcyon-macOS-Universal.tar.gz`.
2. Дважды щёлкните архив — macOS распакует `Port Halcyon.app`.
3. Первый раз запустите через Control-клик по приложению → «Открыть» → «Открыть».
4. Если macOS всё равно блокирует неподписанную сборку, откройте Terminal и выполните команду ниже. После `quarantine` поставьте пробел и перетащите `Port Halcyon.app` в окно Terminal, затем нажмите Enter:

   ```bash
   xattr -dr com.apple.quarantine "/путь/к/Port Halcyon.app"
   ```

macOS-сборка универсальная: внутри есть исполняемый код x86_64 и arm64. Она не подписана Apple Developer ID и не notarized, поэтому Gatekeeper может запросить описанное подтверждение.

Подробный вариант с решениями типичных проблем: [START_HERE.md](START_HERE.md).

## Основное управление

| Клавиша | Действие |
|---|---|
| WASD / мышь | движение или управление транспортом / камера |
| Shift | бег или ускорение |
| Space | прыжок, ручник, вертолёт вверх, газ самолёта |
| Ctrl | нырок, вертолёт вниз, тормоз самолёта |
| F / G | сесть за руль или выйти / сесть пассажиром |
| E | взаимодействие |
| ЛКМ / ПКМ / R | атака / прицел / перезарядка |
| 1–8 / Tab | выбор оружия / колесо оружия |
| M / P | карта / телефон |
| V | смена камеры |
| Esc | пауза и настройки |
| F1 | меню быстрого тестирования и телепортов |
| F5 / F9 | быстрое сохранение / загрузка |

Полная таблица управления и архитектура проекта находятся в [DEVELOPMENT.md](DEVELOPMENT.md). Фактическое покрытие функций — в [FEATURE_MATRIX.md](FEATURE_MATRIX.md), итоговый отчёт — в [OPUS_5.5_FINAL_REPORT.md](OPUS_5.5_FINAL_REPORT.md).

## Запуск исходников в Unity

1. Установите Unity Hub и Unity **6000.6.0f1** с модулями Windows Build Support и/или Mac Build Support.
2. В Unity Hub нажмите `Add` → `Add project from disk` и выберите папку `GTA Opus 5.5 Unity`.
3. Дождитесь импорта пакетов.
4. Откройте `Assets/GTA/Scenes/PortHalcyon.unity` и нажмите Play.

Сборки из редактора: меню `Halcyon/5 Build Windows Player`, `Halcyon/6 Build macOS Player` или `Halcyon/7 Build Windows + macOS Players`.

## Содержимое репозитория

- `Assets/`, `Packages/`, `ProjectSettings/` — Unity-проект.
- `UnityOpus5.5GTA.blend` — мастер-файл Blender.
- `Claude_Opus_5.5_Unity_GTA_BlenderMCP_Prompt.md` — исходный промпт задания, сохранён без удаления.
- `QA/` — логи проверок и контактные листы скриншотов.

Сгенерированные `Library`, `Temp`, `Logs`, пользовательские настройки, резервные копии, локальные пути, служебные журналы агента и бинарные сборки в Git не входят. Готовые игры распространяются через GitHub Releases.
