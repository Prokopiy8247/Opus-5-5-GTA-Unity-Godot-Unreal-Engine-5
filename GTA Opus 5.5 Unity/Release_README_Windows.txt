PORT HALCYON — WINDOWS

1. Полностью распакуйте ZIP-архив.
2. Запустите PortHalcyon.exe.
3. Не отделяйте EXE от папки PortHalcyon_Data и остальных файлов.

SmartScreen может предупредить о неизвестном издателе: эта бесплатная
сборка не подписана коммерческим сертификатом. Нажмите "Подробнее" и
"Выполнить в любом случае", только если архив скачан из официального релиза:
https://github.com/Prokopiy8247/Opus-5-5-GTA-Unity-Godot-Unreal-Engine-5/releases

F1 — меню быстрого тестирования, Esc — пауза, WASD/мышь — движение/камера.
