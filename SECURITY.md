# Security

Не публикуйте в issues или pull requests ключи API, токены, пароли, приватные логи, файлы `.env`, сведения из менеджера учётных данных или локальные каталоги `Saved`, `Intermediate` и `DerivedDataCache`.

Если вы обнаружили секрет в истории репозитория, не дублируйте его в публичном issue. Свяжитесь с владельцем репозитория через его публичный профиль GitHub и укажите только путь к файлу и коммит без самого секрета.
