# Запуск Vesper Bay на Windows

## Самый простой способ

1. Скачайте [VesperBay-Windows-x86_64.zip](https://github.com/Prokopiy8247/Opus-5-5-GTA-Unity-Godot-Unreal-Engine-5/releases/download/godot-v1.0.0/VesperBay-Windows-x86_64.zip).
2. Нажмите правой кнопкой по ZIP → **Извлечь всё**.
3. Откройте извлечённую папку и дважды нажмите `VesperBay.exe`.

Устанавливать Godot не нужно. В архиве один самодостаточный EXE.

Если SmartScreen показывает предупреждение, нажмите **Подробнее** → **Выполнить в любом случае**.
Сборка не подписана коммерческим сертификатом; скачивайте её только со страницы Releases этого
репозитория и при желании сверяйте SHA-256 из описания релиза.

## Основное управление

- WASD — движение, Shift — бег, Space — прыжок, мышь — камера.
- ПКМ — прицел, ЛКМ — огонь, R — перезарядка, Tab — выбор оружия.
- F — сесть/выйти из транспорта, E — взаимодействие, V — смена камеры.
- M — карта, F1 — тестовое меню, F5/F9 — быстрое сохранение/загрузка.

Полное управление: [DEVELOPMENT.md](DEVELOPMENT.md#controls-keyboardmouse-gamepad-mapped-as-well).
