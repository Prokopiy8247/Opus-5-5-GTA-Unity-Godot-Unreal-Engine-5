# Opus 5.5 GTA — Unity, Godot и Unreal Engine 5

Публичный монорепозиторий GTA-подобных sandbox-проектов, созданных для сравнения трёх игровых
движков.

## Проекты

| Движок | Папка | Статус |
|---|---|---|
| Godot | [GTA Opus 5.5 Godot](./GTA%20Opus%205.5%20Godot/) | Опубликован — Vesper Bay |
| Unreal Engine 5 | [GTA Opus 5.5 Unreal Engine 5](./GTA%20Opus%205.5%20Unreal%20Engine%205/) | Опубликован — Port Halcyon |
| Unity | `GTA Opus 5.5 Unity` | Будет добавлен отдельно |

[Windows](GTA%20Opus%205.5%20Godot/RUN_WINDOWS.md) ·

Release.

наборы ассетов, ключи API, токены, локальные журналы или данные агентских сессий.
