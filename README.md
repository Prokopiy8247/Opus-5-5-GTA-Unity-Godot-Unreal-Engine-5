# Opus 5.5 GTA — Unity, Godot и Unreal Engine 5

Публичный репозиторий сравнения GTA-подобных sandbox-проектов, созданных для трёх игровых движков.

## Проекты

| Движок | Папка | Статус |
|---|---|---|
| Unreal Engine 5 | [GTA Opus 5.5 Unreal Engine 5](./GTA%20Opus%205.5%20Unreal%20Engine%205/) | Опубликован |
| Unity | `GTA Opus 5.5 Unity` | Будет добавлен отдельно |
| Godot | `GTA Opus 5.5 Godot` | Будет добавлен отдельно |

Для обычной игры на Windows откройте [последний GitHub Release](https://github.com/Prokopiy8247/Opus-5-5-GTA-Unity-Godot-Unreal-Engine-5/releases/latest), скачайте Windows-архив, распакуйте его и запустите `Play Port Halcyon.bat` или `Unreal_Opus5_5_GTA.exe`.

Исходный prompt сохранён внутри папки Unreal-проекта. Репозиторий не содержит Unreal Engine, платных наборов ассетов, ключей API, токенов, локальных журналов или данных агентских сессий.
